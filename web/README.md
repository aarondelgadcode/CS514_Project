# Recipe Finder Website

Refer to the instructions of the `README.md` file inside `backend/` folder to set up the backend before running the website.  

## How to Get Started

1. Navigate to the `web/` directory:
   ```
   cd web
   ```
2. Install the necessary packages:
   ```
   npm install
   ```
3. To start the application locally, run:
   ```
   npm run dev
   ```
4. Go to `localhost:5173` to see the website
